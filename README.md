# SuperNPU Plan Board

用于维护 SuperNPU 算子工作状态、版本发布计划、验证结果和发布特性的交互式工作看板。

## 在线访问

[打开 SuperNPU Plan Board](https://lvhao7896.github.io/supernpu-plan-board/)

## 使用方式

- 工作卡中的标题、说明、问题总结、下一步和阶段名称可以直接编辑；
- 状态、优先级和阶段状态可以通过下拉框调整；
- 拖动工作卡左上角的手柄可以调整排序；
- 点击列表末尾的“＋”卡片可以快速新增工作卡；
- 点击卡片底部的“保存修改”，数据会保存在当前浏览器；
- 需要把修改同步给其他访问者时，导出 `plan_data.json`，替换仓库中的同名文件后提交。

## 本地预览

```bash
python3 -m http.server 8077
```

然后访问 `http://127.0.0.1:8077/`。
